Materials

Raw materials for the recipes. A material can hold several alternatives — approved ones and candidates still in lab or production testing (dashed). ● marks the one mixed in production now; its price and as-delivered concentration are what the recipes use. Lab weighing names it at every component and lets you pick another one for a weighing.

Gist sync settings

Data is encrypted in this browser before upload (AES-256-GCM) — GitHub stores only unreadable ciphertext. The token, Gist ID and key stay on this device.

Create a token at github.com/settings/tokens (scope gist). You can find your gists at gist.github.com.

Recovery key

If you forget the passphrase, this key unlocks the synced data and lets you set a new passphrase. It is shown only now — save it outside this app: a password manager, a printout, or e-mail it to yourself. It stays valid until you change the passphrase without it or create a new one.

Anyone with this key and the Gist ID can read the data — do not keep it together with the sync link. A copy may stay in the clipboard history (Win+V, phone keyboard).
